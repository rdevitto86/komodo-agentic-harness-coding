# readiness

## readiness.1

Changed behaviour has a test that fails without the change. Each behaviour the diff changes has a test in the diff or beside it, and the test would fail on the code before the change. A test that passes with or without the change does not count. Quote the changed function that no test covers.

## readiness.2

Documents and the changelog are touched when a task says so. When a task card names a document or the changelog, the diff changes it. Quote the task line that names the document the diff leaves unchanged.
