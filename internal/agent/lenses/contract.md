# contract

## contract.1

Every caller of a changed exported symbol still compiles and behaves as before. Search for the callers of each changed exported symbol; the brief lists the callers of Go symbols, and for other languages you search. A caller the diff leaves broken is a finding. Quote the call site that no longer matches the changed symbol.

## contract.2

A task intends each changed exported symbol. An exported name, signature or field changes only when a task card calls for it. Quote the changed declaration that no task names.
