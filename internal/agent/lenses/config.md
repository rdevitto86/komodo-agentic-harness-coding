# config

## config.1

Hard limits stay at their stated values. No change widens or removes a hard limit in an embedded file. Quote the line that changes a hard limit.

## config.2

The schema version is raised when the shape of the data changes. A change to the shape of an embedded file raises its version. Quote the changed field whose version line is unchanged.

## config.3

The gate fixture matches the changed policy. A changed guard row has a fixture case that proves it. Quote the policy row that has no matching fixture case.
